# UI 规格

> AI 对「好看」没有判断力，所以这里不写形容词，只写数值。
> 实现偏离本文件任何一条 = 返工。

## 1. 页面结构

```
┌──────────────────────────────────────────────────────────┐
│ header 56px：logo + 标题 + 右上角 backend 角标            │
├──────────────┬───────────────────────────────────────────┤
│ 左侧栏 320px │ 主区（自适应）                             │
│ 固定宽度     │ ┌─ KPI 行 72px（5 张卡片）──────────────┐ │
│ 独立滚动     │ ├─ 图 A：决策堆叠柱 260px ──────────────┤ │
│              │ ├─ 图 B：水位折线 200px ────────────────┤ │
│              │ └─ 拒绝原因条 48px ─────────────────────┘ │
└──────────────┴───────────────────────────────────────────┘
```

- 整页高度 `100vh`，**不出现整页滚动条**；只有左栏内部可滚动
- 间距基数 8px：区块间距 16px，卡片内边距 12px
- 圆角：卡片 8px，按钮 6px，标签 4px

## 3. 左侧栏

### 3.1 算法选择（4 张单选卡）

- 每张卡：`displayName`（14px/600）+ `summary`（12px/`--muted`，最多 2 行）
- 选中态：左侧 3px `--accent` 竖条 + 背景 `#1e2537`
- 顺序固定：固定窗口 → 滑动窗口 → 令牌桶 → 漏桶

### 3.2 参数表单

由 `GET /api/algorithms` 的 `params` 动态渲染，**不得硬编码**：

- `type=int|double` → `<input type="number">`，`min/max/step` 直取元数据
- 标签右侧显示单位（`unit` 字段），无则不显示
- 越界时输入框描边 `#ef4444`，下方 12px 错误文案

### 3.3 流量模式

- `<select>`：恒定 / 阶跃 / 尖峰 / 泊松
- 切换后**只显示该模式的字段**（恒定 1 个、阶跃 1 个文本框接受 `1000:10,3000:50` 格式、尖峰 3 个、泊松 2 个）
- 恒定模式 QPS 用 `<input type="range" min=1 max=200>` + 右侧数字

### 3.4 倍速

- 分段控件：`1x 5x 10x 20x 50x`，默认 `10x`
- 选中项背景 `--accent`，文字白

### 3.5 操作按钮（一行三枚，等高 36px）

| 按钮 | 样式 | 可用条件 |
|---|---|---|
| 开始 | 实心 `--accent` | `idle` / `paused` |
| 暂停 | 描边 | `running` |
| 重置 | 描边 `--muted` | 非 `idle` |

## 4. 图 A · 决策堆叠柱

- 尺寸：宽 = 主区宽 - 32px，高 260px（canvas 实际像素乘 `devicePixelRatio`）
- 内边距：`left 48, right 16, top 12, bottom 24`
- X 轴：逻辑时间，固定显示最近 **30 秒**（300 个采样点），刻度每 5 秒一个，标签 `-25s … 0s`
- Y 轴：`请求数/100ms`，从 0 起，上限 = `max(观测最大值, qps*0.12)` 向上取整到 5 的倍数
- 每根柱宽 = `可用宽度 / 300 - 1`（最小 1px），放行在下（`--passed`），拒绝在上（`--rejected` 斜纹）
- 网格线：水平 4 条，`#1f2937`，1px
- 无数据时：居中显示 `--muted` 文案「点击开始实验」

## 5. 图 B · 水位折线

- 尺寸：同图 A 宽，高 200px；内边距与 X 轴刻度与图 A **严格对齐**
- Y 轴：固定 `0% ~ 100%`，刻度 0/50/100，标签带 `%`
- 折线：`--level`，线宽 2px；下方填充 `rgba(34,197,94,0.12)`
- 当前值在右上角显示为 `NN%`，14px
- 图例：左上角 12px 文字，内容随算法变化（固定窗口→「窗口占用」，令牌桶→「令牌余量」，漏桶→「队列水位」）

## 6. 拒绝原因条

- 高 48px，横向排列 4 个 chip（`WINDOW_LIMIT` / `QUEUE_FULL` / `NO_TOKEN` / `PASSED`）
- 每个 chip：`原因名 + 累计次数`，12px；计数为 0 时降为 `--muted` 且不占强调色
- 排序固定，不按次数重排

## 7. 交互与状态

| 行为 | 结果 |
|---|---|
| 点「开始」 | `POST /control {start}`，按钮态切换，SSE 开始收帧 |
| 点「暂停」 | `POST /control {pause}`，图冻结但保留数据 |
| 点「重置」 | `POST /control {reset}`，清空环形缓冲，两图清屏回空态 |
| 切算法 / 改参数 / 改倍速 | 暂停 → `DELETE` → `POST` 新实验 → 保持倍速 → 不自动开始 |
| 鼠标悬停图 A/B | 垂直参考线 + tooltip（`t`、`offered/passed/rejected`、`level`），跟随鼠标，距边 8px 处翻转 |
| SSE 断开 | header 角标变红点 + 文案「连接断开」，3 秒后自动重连（`EventSource` 默认行为） |

- 首屏加载：拉 `/api/algorithms` → 渲染表单 → 拉 `/api/health` → 显示角标
- 请求失败：右上角 toast，3 秒消失，文案取 `error.message`

## 8. 响应式

- 宽度 `< 900px`：左栏折叠为顶部抽屉（按钮「参数」展开），主区占满
- 宽度 `< 600px`：KPI 卡片改为 2 列换行，图高分别降为 180/140

## 9. 明确不做

- 不做主题切换、不做玻璃拟态/渐变背景、不做入场动画
- 不引入任何图标库；需要图标时用 Unicode 或内联 SVG
- 不做移动端手势
