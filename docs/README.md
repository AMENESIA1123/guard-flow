## 阅读顺序（冷启动）

`AGENTS.md` → `PROGRESS.md` → `tasks.md` 找到当前卡 → 按卡上「参考文档」跳转。

## 维护规则

- 改动行为前先改规格，再改代码；**不允许**改测试向量来迁就实现。
- 规格里的编号（`FW-01`、`TB-05`…）是稳定标识，测试方法名必须包含它，便于双向追溯。

## 附录：GIF 分镜脚本（5 步）

录屏建议 1280×720、30–40 秒，保持同一参数基线：`limit/capacity=10`、窗口/速率 `1000ms` 或 `2/s`、输入恒定 `20qps`、倍速 `10x`。

1. **固定窗口的边界突发**：选择「固定窗口」，窗口配额 10、窗口长度 1000ms，开始；把镜头对准决策柱和水位线，停在窗口切换瞬间，让观众看到两个相邻窗口各放行 10 个请求。
2. **滑动窗口削掉突发**：切到「滑动窗口」，保持 10/1000ms，开始；同样 20qps 下不再出现边界双倍放行，水位稳定在配额附近，对比固定窗口的柱形节奏。
3. **令牌桶的突发与锯齿**：切到「令牌桶」，容量 10、补充速率 2/s，开始；先让桶以空桶为主（大量拒绝），再展示每次补充到 1 个令牌时的放行尖峰与水位锯齿。
4. **漏桶的削峰填谷**：切到「漏桶」，队列容量 10、流出速率 2/s，开始；突发时队列满即拒绝，空闲后按固定间隔出队，水位呈阶梯下降，与令牌桶的「空闲后突发」形成对照。
5. **分布式模式锁 1x**：切到 distributed profile（页面顶部角标 `redis`），选择令牌桶；展示倍速控件整体置灰、提示「Redis 版按服务器真实时间计时，不支持倍速」，并说明 Redis 判定使用服务器墙钟，不能用虚拟时钟加速。最后 reset，确认页面归零。
